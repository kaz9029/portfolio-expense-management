# 経費管理システム

Googleフォーム・Googleスプレッドシート・Google Apps Script（GAS）を使用して作成した経費管理システムです。

## 概要

フォームから申請された経費情報をスプレッドシートに自動保存し、経費番号の自動採番、承認状況の管理、メール通知、月別集計を行えるようにした学習用ポートフォリオです。

## 主な機能

- Googleフォームから経費申請を入力
- スプレッドシートへ自動保存
- 経費番号の自動採番
- 承認状況の管理
- 承認時のメール通知
- メール送信状況の自動記録
- 月別集計

## 使用技術

- Googleフォーム
- Googleスプレッドシート
- Google Apps Script（GAS）
- スプレッドシート関数

## 作成目的

Googleフォームとスプレッドシートを使って、実務で使われる経費申請・承認フローの基本を学ぶために作成しました。

## 工夫した点

- 経費番号を自動で付与できるようにした点
- 承認状況を管理できるようにした点
- 承認済みに変更した際、申請者へメール通知が届くようにした点
- 二重送信を防ぐため、メール送信状況を記録するようにした点
- 月別集計で経費の全体像を確認できるようにした点
